# Active-Directory-lab
Windows Server Active Directory home lab demonstrating domain setup, user management, Group Policy, and Windows 10 client integration.
Skills demonstrated:

- Active Directory Domain Services
- Organizational Units (OUs)
- An IT Organizational Unit was created to simulate a department environment. Five user accounts were created and organized within the IT OU to demonstrate Active Directory user management.
- User Management
- Security Groups
- Group Policy
- Windows Server Administration
- DNS
- DHCP
- Domain Join
- Troubleshooting
